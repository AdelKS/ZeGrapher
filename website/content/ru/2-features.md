# Возможности

ZeGrapher строит на плоскости математические объекты — функции,
последовательности, параметрические уравнения, данные — и экспортирует ровно
то, что вы видите на экране.

- **Функции** записываются так же, как на бумаге: `f(x) = 2 + cos(x)`. Доступны
  привычные математические функции и все объекты, которые вы задали сами.
- **Последовательности** — по рекуррентному соотношению, вместе с первыми
  членами: `u(n) = 0 ; 1 ; u(n-2) + u(n-1)`.
- **Параметрические уравнения**, построенные на выбранном вами промежутке.
- **Константы и переменные**, общие для всех объектов: одно значение управляет
  целым семейством кривых. Константа может:
    - меняться ползунком между двумя границами — вручную или с анимацией
    - принимать несколько значений сразу, и тогда каждая кривая с этой
      константой строится для каждого значения
- **Данные** импортируются из CSV и редактируются в таблице, как в табличном
  редакторе. Проверено на файлах в несколько миллионов ячеек.
- **Связанные объекты**: любой именованный объект можно использовать в
  выражении другого и в ячейках столбца данных.
- **Интерактивный график**: перетаскивание двигает вид, колесо меняет масштаб — в
  том числе по одной оси.
- **Гибкая настройка сетки**: деления, кратные выражению вроде `π`, свои
  подразделения и свои цвета для x и для y.
- **Экспорт, в точности повторяющий экран**, в векторном формате (`svg`, `pdf`)
  или изображением (`png`, `jpeg`, `bmp`, `ppm`). Размер задаётся в реальных
  сантиметрах.
- **Продолжайте с того места, где остановились**: программа сохраняет вашу
  работу при закрытии и восстанавливает её при следующем запуске. Её можно сохранить
  и в свой файл, а потом открыть когда угодно.
- **Встроенное руководство** открывается рядом с графиком, на языке
  программы.
- **10 языков**: программа и её руководство есть на английском, французском,
  немецком, испанском, итальянском, португальском, русском, японском,
  китайском и арабском.
