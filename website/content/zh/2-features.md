# 功能

ZeGrapher 在平面上绘制数学对象——函数、数列、参数方程和数据——
并把你看到的画面原样导出。

- **函数**，写法和纸上一样，`f(x) = 2 + cos(x)`。
  常用数学函数随时可用，你自己定义的对象也一样。
- **数列**，由递推关系定义，前几项一并写在里面：
  `u(n) = 0 ; 1 ; u(n-2) + u(n-1)`。
- **参数方程**，在你指定的区间上绘制。
- **常量与变量**，为所有对象共用，一个值就能带动一整族曲线。一个常量可以
    - 在两端之间沿滑块移动，手动拖动或播放成动画，
    - 同时取多个值，用到它的每条曲线便按值逐一绘制。
- **数据**，从 CSV 导入，已在数百万单元格的文件上验证过，还能像电子表格一样
  在表格里编辑。
- **对象同处一个世界**：任何具名对象都能出现在另一个对象的表达式里，
  数据列的单元格里也一样。
- **可自由操控的图**：拖动平移，滚轮缩放，还能只缩放其中一根轴。
- **细致到网格的自定义**：刻度可以取 `π` 之类表达式的倍数，
  x 和 y 的细分数与颜色也能各设各的。
- **导出与预览分毫不差**，可存为矢量格式（`svg`、`pdf`）或图像
  （`png`、`jpeg`、`bmp`、`ppm`）。尺寸按真实厘米或按像素给出。
- **你的工作会存进文档**，下次启动时原样打开。
