# 功能

ZeGrapher 在平面上绘制数学对象——函数、数列、参数方程和数据——
并把你看到的画面原样导出。

- **函数**的写法和纸上一样，例如 `f(x) = 2 + cos(x)`。
  既可以使用常用数学函数，也可以使用你自己定义的对象。
- **数列**由初始项和递推关系定义：
  `u(n) = 0 ; 1 ; u(n-2) + u(n-1)`。
- **参数方程**，在你指定的区间上绘制。
- **常量与变量**，为所有对象共用，一个值就能控制一整族曲线。一个常量可以：
    - 通过滑块在两个边界之间变化，可以手动拖动，也可以播放动画
    - 同时取多个值，用到它的每条曲线会针对每个值各绘制一次
- **数据**，从 CSV 导入，还能像电子表格一样在表格里编辑。已在数百万单元格的
  文件上验证过。
- **对象之间可以互相引用**：任何具名对象都能出现在另一个对象的表达式里，
  也能出现在数据列的单元格里。
- **交互式图形**：拖动平移，滚轮缩放，还能只缩放其中一根轴。
- **网格随心定制**：刻度可以取 `π` 之类表达式的倍数，
  x 和 y 的细分数与颜色也能各设各的。
- **导出与预览分毫不差**，可存为矢量格式（`svg`、`pdf`）或图像
  （`png`、`jpeg`、`bmp`、`ppm`）。尺寸以真实厘米为单位设定。
- **接着上次继续**：关闭时会自动保存你的工作，下次启动时自动恢复。
  你也可以另存为自己的文件，随时再打开。
- **内置使用手册**，在图旁边打开，语言与应用一致。
- **支持 10 种语言**：应用及其手册有英语、法语、德语、西班牙语、意大利语、
  葡萄牙语、俄语、日语、中文和阿拉伯语版本。
