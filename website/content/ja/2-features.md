# できること

ZeGrapher は関数、数列、媒介変数表示、データといった数学の対象を平面に描き、
画面で見たままを書き出します。

- **関数**は紙に書くのと同じ形で書きます。`f(x) = 2 + cos(x)`。
  よく使う数学関数も、自分で定義した対象も、そのまま使えます。
- **数列**は漸化式で書きます。最初の項も一緒に並べます：
  `u(n) = 0 ; 1 ; u(n-2) + u(n-1)`。
- **媒介変数表示**を、指定した区間に描きます。
- **定数と変数**はすべての対象で共通です。値を一つ動かすと、曲線の一族が
  まとめて動きます。定数は
    - スライダーで両端の間を動かせます。手でも、アニメーションでも。
    - 一度に複数の値をとれます。その定数を使う曲線を、値の数だけ描きます。
- **データ**は CSV から読み込みます。数百万セルのファイルでも動作を
  確かめました。表計算ソフトのように表で編集できます。
- **対象は一つの世界にあります**。名前のついた対象は、別の対象の式にも、
  データ列のセルにも書けます。
- **マウスで動かせるグラフ**。ドラッグで移動、ホイールでズーム、軸を片方だけ
  ズームすることもできます。
- **グリッドまで思いどおりに**。目盛りを `π` などの式の倍数にできます。
  x と y で分割数も色も別々に決められます。
- **書き出しは画面と同じ**。ベクター形式（`svg`、`pdf`）でも画像
  （`png`、`jpeg`、`bmp`、`ppm`）でも。大きさは実寸のセンチメートルでも
  ピクセルでも指定できます。
- **作業はドキュメントに保存**され、次の起動でそのまま開きます。
