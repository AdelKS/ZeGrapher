# できること

ZeGrapher は関数、数列、媒介変数表示、データといった数学のオブジェクトを平面に描き、
画面で見たままを書き出します。

- **関数**は紙に書くのと同じように入力できます（例：`f(x) = 2 + cos(x)`）。
  よく使う数学関数も、自分で定義したオブジェクトも、そのまま使えます。
- **数列**は初項と漸化式で定義します：
  `u(n) = 0 ; 1 ; u(n-2) + u(n-1)`。
- **媒介変数表示**を、好きな区間で描けます。
- **定数と変数**はすべてのオブジェクトで共通です。値を一つ変えるだけで、曲線族が
  まとめて変化します。定数は：
    - スライダーで二つの境界の間を動かせます（手動でもアニメーションでも）。
    - 一度に複数の値をとれます。その定数を使う曲線は、値ごとに描かれます。
- **データ**は CSV から読み込み、表計算ソフトのように表で編集できます。
  数百万セルのファイルで動作を確認済みです。
- **オブジェクトどうしを組み合わせられます**。名前のついたオブジェクトは、別のオブジェクトの式にも、
  データ列のセルにも使えます。
- **マウスで動かせるグラフ**。ドラッグで移動、ホイールでズーム、軸を片方だけ
  ズームすることもできます。
- **グリッドまで思いどおりに**。目盛りを `π` などの式の倍数にできます。
  x と y で分割数も色も別々に決められます。
- **書き出しは画面と同じ**。ベクター形式（`svg`、`pdf`）でも画像
  （`png`、`jpeg`、`bmp`、`ppm`）でも書き出せます。大きさは実寸のセンチメートルで
  指定します。
- **続きからすぐに始められます**。閉じるときに作業を自動保存し、次の起動時に
  復元します。自分のファイルに保存して、好きなときに開くこともできます。
- **マニュアルを内蔵**。グラフの横に、アプリと同じ言語で開きます。
- **10 か国語に対応**。アプリとマニュアルは英語、フランス語、ドイツ語、
  スペイン語、イタリア語、ポルトガル語、ロシア語、日本語、中国語、アラビア語で
  使えます。
